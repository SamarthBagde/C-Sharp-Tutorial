# Operator Overloading

Operator overloading in C# allows you to redefine the behavior of built-in operators (like +, -, *, ==, etc.) so they can work directly with your custom classes or structures.

By default, the compiler does not know how to "add" two custom objects together. Operator overloading bridges this gap, making your custom types feel like native C# data types.

### Core Rules of Operator Overloading

Before looking at code, you must keep these strict C# rules in mind:

- `Must be static and public`: Overloaded operators belong to the class type itself, not a specific instance.

- `Use the operator keyword`: You define them using a special syntax combining `public static [Return_Type] operator [Symbol] (Parameters)`.

- `Unary vs Binary parameters`: Unary operators (like ++) take exactly one parameter. Binary operators (like +) take exactly two parameters.

- `Symmetry in comparisons`: If you overload ==, you must also overload !=. The same applies to < and >, or <= and >=.


Example : Custom Vector2D Math

```c#
using System;

public struct Vector2D
{
    public double X { get; }
    public double Y { get; }

    // Constructor
    public Vector2D(double x, double y)
    {
        X = x;
        Y = y;
    }

    // 1. Overloading the Binary "+" Operator
    public static Vector2D operator +(Vector2D v1, Vector2D v2)
    {
        // Defines exactly how to add two Vector2D objects together
        return new Vector2D(v1.X + v2.X, v1.Y + v2.Y);
    }

    // 2. Overloading the Unary "-" Operator (Inverts the vector coordinates)
    public static Vector2D operator -(Vector2D v)
    {
        return new Vector2D(-v.X, -v.Y);
    }

    // Helper method to easily display our results
    public override string ToString() => $"({X}, {Y})";
}

// ------------------------------------------------------------

class Program
{
    static void Main()
    {
        Vector2D velocity1 = new Vector2D(5.0, 3.5);
        Vector2D velocity2 = new Vector2D(2.0, 1.5);

        // Uses the overloaded "+" operator
        Vector2D totalVelocity = velocity1 + velocity2; 
        Console.WriteLine($"Total: {totalVelocity}"); // Outputs: (7, 5)

        // Uses the overloaded unary "-" operator
        Vector2D reversedVelocity = -velocity1; 
        Console.WriteLine($"Reversed: {reversedVelocity}"); // Outputs: (-5, -3.5)
    }
}
```
